# 제주 태양 관측소 대시보드 — 문서 번들

VS Code + Claude Code로 구현하기 위한 전체 맥락 문서입니다. 코드는 아직 없습니다.

시작 방법
1. 이 폴더를 새 저장소 루트로 사용합니다 (CLAUDE.md가 루트에 있어야 Claude Code가 자동으로 읽습니다).
2. VS Code에서 폴더를 열고 Claude Code를 실행합니다.
3. 첫 프롬프트: "CLAUDE.md를 읽고 docs/06-작업단계-프롬프트.md의 0단계를 시작하세요."
4. 단계마다 완료 조건을 확인하고 체크박스를 갱신하며 진행합니다.

문서 구성
- CLAUDE.md — Claude Code 지시문(스택, 규칙, 기본값, 결정 기록)
- docs/00 개요 · 01 하드웨어/프로토콜 · 02 구현기획 · 03 디자인 확정 · 04 계산 사양(테스트 벡터) · 05 탐구카드 데이터 · 06 작업단계 프롬프트 · 07 수업안/활동지
- docs/reference — 원본 기획서 v1, 해커톤 실행판 v2, 측정기 제작 가이드, 제미나이 화면설계 초안, 주최 측 Web Serial 템플릿 HTML(통신 코드 원본)
